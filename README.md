# PINGER

**Network Ping Latency Monitor**

## Features

- 🚀 Fast and efficient
- 📦 Single binary, no dependencies  
- 🔧 Easy to use
- 🔒 Secure by design

## Installation

```bash
git clone https://github.com/simplestar-992/pinger.git
cd pinger
go build -o pinger .
```

## Usage

```bash
./pinger --help
```

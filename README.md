## ✨ Features

- 🚀 Blazing fast performance
- 💎 Clean and intuitive API
- 🔧 Zero configuration needed
- 🛡️ Secure by default
- 📦 Single binary, no dependencies

## 📥 Installation

```bash
git clone https://github.com/simplestar-992/pinger.git
cd pinger
go build -o pinger .
./pinger --help
```

## 🚀 Quick Start

```bash
./pinger -h
```

## 🧪 Examples

```bash
# Example 1
./pinger status

# Example 2  
./pinger --verbose

# Example 3
./pinger help
```
